像 App 一樣用

放到手機桌面，一點就開

三步就好，不用去應用商店，不用下載，不花錢。裝好後，桌面上有一個綠色的“叮”字圖標，點一下就能打開生活指南；沒有網絡時，也能看上次打開過的內容。

回到首頁

先看這裏

在微信裏打開的，裝不了

微信裏打開的網頁，沒有“放到桌面”這個功能。如果你是從微信點進來的：

  1. 點右上角“···” 在微信右上角。
  2. 選“在瀏覽器打開”蘋果手機會寫“在 Safari 打開”，安卓手機會寫“在瀏覽器打開”。
  3. 打開後，照下面做蘋果手機看“蘋果手機”，其他手機看“安卓手機”。

蘋果手機（iPhone）

用 Safari 瀏覽器，三步

  1. 點底部中間的“分享”按鈕 樣子是一個方框，裏面有個向上的箭頭。
  2. 往上滑，點“添加到主屏幕” 在列表裏找，滑一滑就看到。
  3. 點右上角“添加”桌面上就出現綠色“叮”字圖標。

用 Chrome 或其他瀏覽器的蘋果手機，一般也在“分享”菜單裏有“添加到主屏幕”；找不到，就換成 Safari。

安卓手機

用 Chrome 瀏覽器，三步

  1. 點右上角“⋮” 三個豎着的小點。
  2. 點“安裝應用”或“添加到主屏幕” 兩個名字都可能出現，點哪個都行。
  3. 在彈出的框裏點“安裝”或“添加”桌面上就出現綠色“叮”字圖標。

華為、小米、OPPO、vivo 等自帶的瀏覽器，菜單裏叫“添加到桌面”或“添加書籤到桌面”，意思一樣。

裝好以後

它和平時看網頁有什麼不同

一點就開像別的 App 一樣，不用再記網址或翻聊天記錄。

沒網也能看上次打開過的頁面，沒有網絡時還在；頁面頂上會提醒你“現在沒有網絡”。打電話和查最新場次，還是要有信號。

內容自動更新活動和服務有更新，下次聯網打開就是新的，不用重新安裝。

不要你的資料不用註冊，不用登錄。想刪掉，像刪別的 App 一樣，長按圖標刪除就好。

拿到爸媽的手機，照上面三步裝一次，再把圖標放在第一頁。以後他們只用點一下“叮”字。
